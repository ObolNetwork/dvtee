# Security policy

sev-signer is experimental. It has not run on SEV-SNP hardware, has not been audited, and must not
hold mainnet keys. The gaps we already know about are listed in
[ROADMAP.md](ROADMAP.md#known-gaps); there is no need to report those.

To report anything else, use GitHub's
[private vulnerability reporting](https://github.com/ObolNetwork/sev-signer/security/advisories/new)
for this repository. Please don't open a public issue for a vulnerability.

There is no bug bounty for this repository while it is experimental.
