# Security policy

sev-signer is experimental. It has not run on SEV-SNP hardware, has not been audited, and must not
hold mainnet keys. The gaps we already know about are listed in
[ROADMAP.md](ROADMAP.md#known-gaps); there is no need to report those.

To report anything else, follow Obol's
[security contact process](https://docs.obol.org/advanced-and-troubleshooting/security/contact).
Please don't open a public issue for a vulnerability.

sev-signer is not in scope for the
[Obol bug bounty](https://docs.obol.org/advanced-and-troubleshooting/security/bug-bounty) while it is
experimental.
